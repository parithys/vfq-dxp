# Open UI Tablet — Fixed Line, Prepatched KID, Combo Box, Normal Activation — Full Click-Through Walkthrough

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots show an in-app system date of Sunday, February 08, 2026)

## Purpose
Shows a Vodafone Qatar front-line agent (Open UI on tablet) how to sell and provision a Fixed Line "Triple Play" service (GigaHome broadband + Home Phone + optional IPTV) at a customer's premises where a ComboBox CPE/ONT device has already been physically installed ("prepatched"), using the **Normal Activation** path (as opposed to Instant Activation) with a Combo Box (device-detected) Kahramaa address record. It also documents the downstream Team Manager order-approval step, a reject/correction cycle, and the resulting backend CRM records (Sales Order, Account, Contact) so agents can see the full order lifecycle, not just the sales screens.
