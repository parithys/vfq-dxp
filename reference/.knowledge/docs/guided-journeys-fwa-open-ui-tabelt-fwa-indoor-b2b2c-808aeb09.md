# New FWA Tablet (Indoor, B2B2C) — End-to-End Guided Journey: Order Creation, CAF Signing, Approval, and Fulfillment

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots are timestamped 17-Sep-2025 in-app; captured on a QA/UAT environment "10.162.53.100:4443", tab labeled "QA7 IP15.5")

## Purpose
A click-through walkthrough of the Vodafone Qatar Open UI ("Siebel"-based CRM, "eCommunications_OUI") tablet journey for selling a new Fixed Wireless Access (FWA) Indoor plan to a B2B2C consumer customer — from contact verification through plan/add-on selection, SIM/CPE serial validation, CAF (Customer Application Form) digital signature, document attachment, order submission, manager approval, and final order/asset fulfillment. It also documents the corresponding backend Siebel/UIM screens an agent or approver would cross-check (contact/account record, number inventory, SIM/CPE lookup in Oracle UIM, order approval queue, installed assets, billing profile).
