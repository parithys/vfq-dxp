# Open UI Tablet – MNP Prepaid (Mobile Number Portability into Vodafone Prepaid) Walkthrough

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, Open UI guided-wizard path (accordion/wizard steps within Siebel Web Call Center "MNP Tablet" module)
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots carry an in-app clock/date of Tuesday, 22-Sep-2020, which is test/demo system data, not a document date)

## Purpose
Demonstrates the end-to-end agent flow, on the Open UI Tablet channel, for porting a customer's mobile number from another Qatari operator ("donor" operator, e.g. Ooredoo/Qtel) into a new Vodafone **Prepaid** subscription (MNP Prepaid), from customer ID lookup through SIM allocation, donor/porting details capture, e-signature on the MNP and CAF (Customer Application Form) contracts, and order completion.
