# Open UI Tablet – Creating a Postpaid Lead from a Mobile Number, then Manager Review and Reassignment

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path
**Owner / author:** not stated
**Date:** not stated in content or filename

## Purpose
Shows a Retail Agent (Hemanth Kumar) creating a new sales Lead from a customer's mobile number on the Open UI Tablet CRM Home page, filling in service/contact details, submitting the lead, then editing its callback time, status and sub-status from "My Leads." The second half of the walkthrough switches to a Retail Store Manager ("Test Manager") login who opens the same lead from "Manage Leads" and reassigns (changes the Lead Owner) to another Retail Agent.
