# Fixed Line Normal Activation (Tablet, Combo Box) — Order Approval, Rejection & Correction Journey

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path (New Fixed Line Tablet journey) plus back-office Order Approval / Order Correction screens
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots show in-app date "Sunday, February 08, 2026" / "08-02-2026" and timestamps 10:38–12:43 the same day — this is test/demo data, not the doc's authoring date)

## Purpose
Demonstrates the full field-agent-to-back-office lifecycle for a **Fixed Line "Normal Activation"** sale on the **Open UI Tablet** channel using a **Combo Box (ONT/CPE) device**, where the resulting Sales Order requires supervisor **Order Approval**. It walks through: creating the order end-to-end on the tablet, the order landing in a Test Manager's approval queue, the manager **rejecting** the order with a reason and comment, the system-generated rejection SMS, and the agent going back into a dedicated **"Order Correction"** tablet journey to fix and resubmit the contact/ID details. It also shows the resulting order and audit trail in the Siebel desktop/back-office views.
