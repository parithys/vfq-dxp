# Tablet Fixed Line New Connection: Prepatched Combo Box CPE, Instant Activation (Vodafone Qatar Open UI)

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path (numbered accordion steps 1-8)
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots carry an in-app clock showing 3-Feb-2026, ~2:30-2:41 PM, and a CAF document date of 3-Feb-2026 — this is simulation/test-environment timestamp data, not the document's authorship date)

## Purpose
A tablet-agent walkthrough of the Vodafone Open UI "New Fixed Line Tablet" guided journey for a new Fixed Line (GigaHome broadband) connection at a site where the CPE/ONT combo device is already pre-installed ("prepatched") at the customer's premises. The journey demonstrates the system auto-detecting the pre-patched Combo Box device by serial number and offering the agent a choice between Instant Activation and Normal Activation — this walkthrough follows the Instant Activation branch through to a completed order.
