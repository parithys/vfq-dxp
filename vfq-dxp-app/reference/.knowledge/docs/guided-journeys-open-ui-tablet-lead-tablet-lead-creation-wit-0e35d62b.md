# Tablet Lead Creation with Fixed Pre-Sales Flag and Subsequent Lead Edit (Service Needed change)

**Type:** Guided Journey walkthrough (step-by-step UI screenshots for field agents), Tablet, guided-wizard path
**Owner / author:** not stated
**Date:** not stated in content or filename (screenshots show in-app system date/time of Monday, December 01, 2025, ~17:10–17:54, and a scheduled callback of 12/25/2025)

## Purpose
Demonstrates, via 13 sequential UI screenshots, how a Vodafone Qatar agent creates a new Lead from the tablet Open UI ("New Lead Tablet" tile), marks it as **Fixed Pre-Sales = Yes** (which surfaces an appointment-style Preferred Time picker and an address block), confirms lead creation, then locates that same lead from the customer's Contact record and edits it — changing **Service Needed** from "Home" to "MNP" and updating the free-text **Description** field to "MNP from Home".
