# Open UI Tablet — Fixed Line, Prepatched KID, Non Combo Box, Normal Activation (CRM click-through walkthrough)

**Date:** not stated in content or filename (screenshots are dated 8-Feb-2026, evidently a test/UAT environment — "TestUser", "Test Manager", "TestZSB1" test address data — so this is a training/UAT walkthrough, not a live production date)

## Purpose
A screenshot-driven, step-by-step CRM training/reference guide showing an agent how to complete a New Fixed Line Tablet order in the Vodafone Qatar Open UI (Siebel-based `ecommunications_oui_enu`) for a Kahramaa ID whose Optical Network Terminal (ONT) already has a **Prepatched** KID (i.e. the fibre port/KID is already available and patched at the exchange, no truck-roll needed for patching) and where the property is a **Non Combo Box** location (single dwelling/non-combo service point, as opposed to a shared "Combo Box" MDU scenario documented separately). The guide walks through the full flow: contact/ID capture, address & service-point confirmation, plan selection, add-ons, number reservation, appointment booking, CAF (Customer Application Form) generation and e-signature, order submission, manager approval (including a reject-for-correction round-trip), and backend confirmation via SMS.

### What "Non Combo Box" means as observed (vs. Combo Box variant)
This document's screens never surface a "Combo Box" toggle or field explicitly — "Non Combo Box" is not a distinct on-screen prompt but a characteristic of the **address/service-point topology** selected in Step 5 "Address": the Service Points grid for Kahramaa ID `16P6003` lists standalone Fixed Line Port service points tied to a single ONT (`DeviceID ALCLF11C1516`), i.e. a single dwelling/unit with its own dedicated port rather than a shared combo/MDU box serving multiple units. Because the KID is **Prepatched** (per the backend SOAP trace: `PatchingType=Prepatched`, `KIDStatus=Available`), no separate "Combo Box" selection or shared-infrastructure step (e.g. selecting a shared box/unit number in a multi-dwelling building) appears anywhere in this flow — the journey goes straight from Address confirmation to Plan selection. This is consistent with "Non Combo Box" meaning a straightforward single-unit fixed-line install where the ONT/port is already patched and dedicated, contrasted with a "Combo Box" variant (documented separately) that would require selecting/confirming a shared distribution box serving multiple households.
